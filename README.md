## 🧠 Highlight Project

### 🏆 [LungSight](https://github.com/ZaidH24881/LungSight)

**Top 3 at the UIUC MTC Hackathon — HOPPR: AI for Medical Imaging Workflows**

LungSight is an AI-powered web application that integrates HOPPR APIs and FHIR standards to make radiology AI results more accessible and usable in clinical workflows.

Built with React, Node.js, and Framer Motion.

Key features include:

* Explainable Grad-CAM heatmaps
* Structured FHIR-based reports
* Drag-and-drop medical image uploads
* Multi-study comparison tools
* Dark and light modes
* Responsive clinical workflow interfaces
